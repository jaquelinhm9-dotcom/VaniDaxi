# VaniDaxi

Repositorio del ecosistema VaniDaxi.

Incluye:
- VaniDaxi
- VaniReparte
- Panel Principal VaniDaxi

El workflow `.github/workflows/build-apks.yml` genera las tres APK de depuración en una sola ejecución y las publica como artefacto **VaniDaxi-3-APKs**.

Las claves privadas de release no se almacenan en el repositorio.
