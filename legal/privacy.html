Aviso de privacidad — VaniDaxi y VaniReparte

Este texto describe el tratamiento previsto de datos del ecosistema VaniDaxi. Debe revisarse jurídicamente y completarse con la razón social, domicilio y medios de contacto definitivos antes de publicar en Google Play.

Datos

Podemos tratar nombre, correo, teléfono y datos de perfil; direcciones y ubicación cuando el usuario las proporciona o concede permiso; información de pedidos, ventas, inventario, rutas y entregas; solicitudes de soporte; y datos técnicos necesarios para sesión y seguridad.

Finalidades

Crear y proteger cuentas, permitir compras y ventas, gestionar inventario, procesar pedidos y entregas, facilitar seguimiento, atender solicitudes, prevenir abusos y mantener registros operativos y contables.

Ubicación

VaniDaxi puede utilizar ubicación para registrar una dirección. VaniReparte utiliza ubicación para actualizar la posición necesaria para rutas y entregas. El permiso se controla desde Android.

Pagos

Los pagos pueden procesarse mediante proveedores externos como Mercado Pago. VaniDaxi no debe almacenar contraseñas bancarias, NIP, tokens ni códigos de acceso.

Conservación

Los datos se conservan mientras sean necesarios para prestar el servicio y, cuando corresponda, para obligaciones legales, contables, seguridad, prevención de fraude o resolución de disputas. Cuando una solicitud procede, los datos que no deban conservarse se eliminan o anonimizan.

Eliminación

Las personas con cuenta pueden solicitar la eliminación desde la aplicación o mediante el recurso web. La empresa verificará la solicitud y procesará la eliminación conforme a las obligaciones aplicables.
